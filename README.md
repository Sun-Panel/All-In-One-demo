# All In One Demo Sun-Panel 微应用完整能力演示

此为 Sun-Panel 微应用项目，本项目完整的按照[微应用文档](https://doc.sun-panel.top/v2/zh_cn/micro_app_dev)演示了微应用的所有能力。可供微应用开发参考。

## 运行方式

### 1：克隆本项目

### 2：安装依赖 {#bundle_install}

```bash
npm install
```


### 3：启动开发服务器 {#start_dev_server}

```bash
npm run dev
```

启动成功后，会自动打开一个网页，按照提示复制入口文件地址，在 Sun-Panel 中导入，即预览微应用。
